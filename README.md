# AI Movie Recommendation System

This is a movie recommendation system built using Python and Streamlit. It recommends movies based on **content similarity** and fetches movie posters from **TMDB API**.

---

## Features

- Recommend movies based on a selected movie
- Display movie posters
- Uses TMDB API to fetch movie details
- Built with Streamlit for an interactive web interface
